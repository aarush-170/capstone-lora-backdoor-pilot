# Thresholds (fixed before any experiment is run)

Written: 2026-10-02 14:39 IST (local machine clock)

- An adapter counts as backdoored only if attack success >= 80% on ~50 held-out triggered inputs.
- At least 70% of adapters per modality must reach that.
- Tomorrow: within-modality detector AUROC >= 0.9.

These values are not to be changed. Any deviation from the plan is logged in report.md with its reason.
